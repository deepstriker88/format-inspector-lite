What it does

Check email, IP, UUID and other text formats. Audit CSV or JSON and compare deliveries with a reusable contract.

Limitations: Syntax and format checks only; no mailbox, network or malware verification.

Hosted API example

curl -X POST https://format-inspector.eztoolgo.duckdns.org/v1/inspect \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"format":"email","value":"user@example.com"}'
