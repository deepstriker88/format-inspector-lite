Bulk data import gate

Validate a list of typed values before import. Reports record numbers and verdicts, not original values.

Run in your existing CI

No extra framework or service to install. Node.js 20+ and an optional managed API key.

Download automation runnerDownload example input

1. Preview the check count (free, no connection)

node automation.mjs automation-example.json

2. Run with your subscribed API key

Set EZTOOLGO_API_KEY in your CI secret settings. Only use inputs you are authorized to send. The following command sends the input to this product API and consumes existing monthly quota. It will not fetch any destination URL.

node automation.mjs automation-example.json --send > review-report.json

Exit 0 = preview or pass, 1 = finding, 2 = incomplete or unavailable. Default maximum 100 checks, optionally set --max-checks up to 500. Quota checked before sending; no automatic retries. A connection failure may still consume one call. Reports omit raw values and keys.

GitHub Actions step
      - name: Release gate
        env:
          EZTOOLGO_API_KEY: ${{ secrets.EZTOOLGO_API_KEY }}
        run: node automation.mjs automation-example.json --send > review-report.json

Commit the reviewed runner and your authorized input to your own repository. Do not commit keys or private fixtures.
