# Search demand / SEO policy

Domain: https://format-inspector.eztoolgo.duckdns.org/

Current state: no first-party Search Console query data yet

Rules:
- Do not generate thin keyword pages without Search Console and current SERP/intent evidence
- Keep the landing page focused on the actual free core and optional hosted API
- Canonical, robots.txt and sitemap.xml are included
- Once impressions exist, feed query/page/click/CTR/position into the API Factory search-growth queue
- Prefer title/meta/H1/tool UX improvements before creating a new page
- Evaluate changes on roughly 28-day windows where data volume permits
